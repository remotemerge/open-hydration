Chrome Extension
---
<p>This repository contains the base code to build chrome extension using VanillaJS, ReactJS, VueJS and much more.</p>

Branches
---
**Master:**
<span>The master branch contains the base code for VanillaJS.</span><br/>
`git checkout master`

**React:**
<span>The react branch contains the base code for ReactJS.</span><br/>
`git checkout react`

**Vue:**
<span>The vue branch contains the base code for VueJS.</span><br/>
`git checkout vue`

Installation
---
`yarn` or `npm install`

Run
---
`yarn build` or `npm run build`
