Chrome Extension
---
<p>This repository contains the base code to build chrome extension using VanillaJS, ReactJS, VueJS and much more.</p>

Branches
---
**master:**
<span>The master branch contains the base code for VanillaJS.</span>

**react:**
<span>The react branch contains the base code for ReactJS.</span>

**vue:**
<span>The vue branch contains the base code for VueJS.</span>

Installation
---
`yarn` or `npm install`

Run
---
`yarn build` or `npm run build`
